# picoCTF Labs

Writeups and working files from picoCTF challenges.

## Challenges

- `bases` — encoding/decoding basics
- `bigzip` — recursive archive extraction + grep
- `firstfind` — using `find`
- `FirstGrep` — using `grep`
- `insp3ct0r` — inspecting page source / network requests
- `mod26` — ROT13
- `NiceNetcat` — netcat basics
- `plumbing` — shell pipes/redirection
- `pwcrack` — password cracking (pw1-pw5)
- `pythonWrangling` — scripting a decryption routine
- `staticAintAlwaysNoise` — static binary analysis
- `stringsss` — using `strings`
- `superssh` — connecting over SSH
- `wherearetherobots` — `robots.txt` recon

Each challenge folder has a `notes.md` (or `notes`) with the solve steps.
